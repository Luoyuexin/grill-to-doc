# grill-to-doc

A strategic mentor skill that interviews you with a God's-eye view — balancing rational critique and emotional encouragement — then generates one structured document. (一个具备"上帝视角"的战略导师 Skill：深度拷问方案，最终生成结构化文档。)

Use it when you want to stress-test a plan or a big decision, or just say "grill me" / "拷问方案".

## Features

- **Mentor's Sandwich**: every question pairs 🟢 encouragement with 🔴 critique, 💡 recommendation, and ❓ one focused question.
- **Deterministic exit**: a 6-item coverage checklist (goal / users / scope / constraints / metric / top risk) ends the interview — with an escape hatch anytime.
- **Structured Output**: one document (Summary, Vision, Decisions, Risks, Open Issues) saved to `docs/`, in Markdown or Word.
