# grill-to-doc

A strategic mentor skill that interviews you relentlessly with a God's-eye view, balancing rational critique and emotional encouragement, until generating a structured document. (一个具备"上帝视角"的战略导师 Skill。兼具理性批判与感性鼓励，深度拷问方案，最终生成结构化文档。)

Use it when you want to stress-test a plan, seek a balanced evaluation, or just say "grill me". 

## Features

- **Mentor's Sandwich**: Every question includes 🟢 Encouragement, 🔴 Critique, and 💡 Recommendation.
- **God's-Eye View**: Zooms out from micro-details to macro-level strategy and long-term impact.
- **Structured Output**: Generates full documents (Vision, Risks, Decisions) in Markdown or Word.
